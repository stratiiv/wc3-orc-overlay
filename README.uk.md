# WC3 Orc Overlay

[English](README.md) | **Українська**

Підказки за таймером для Warcraft III: The Frozen Throne (1.26a). Сценарій: Орда проти Нічного ельфа, гра проти ШІ.
Підказки з'являються рядками в зоні чату, як повідомлення. Таймер стартує сам, коли починається матч.

Працює і в **повноекранному режимі**. Рядки малює маленька DLL прямо в кадрі гри (Direct3D 8 і 9).

![приклад](https://github.com/stratiiv/wc3-orc-overlay/releases/download/v1.0/preview.png)

Ще є:
- **Зум камери** на `PageUp` / `PageDown`, крок 150, від 1000 до 3500 (стандартно 1650),
  і **нахил камери** на `Ctrl+PageUp` / `Ctrl+PageDown`. Обидва зберігаються в `%APPDATA%\orc_hints.ini`
  і ставляться на старті кожного матчу (видаліть файл, щоб повернути стандартні).
- **Сіткові гарячі клавіші, як у Reforged**: кожна кнопка на панелі команд отримує клавішу за своїм місцем
  (Q W E R / A S D F / Z X C V).

## Що в репозиторії

| Файл | Що робить |
|------|-----------|
| `orc_hints.txt` | Підказки. Звичайний текст; редагуйте чи перекладайте, перезбирати нічого не треба. |
| `orc.c`, `d3d8hook.c`, `d3d9hook.c`, `orc.h`, `ijl15.def` | Код `orc_hints.dll`. |
| `test_proxy.c` | Перевіряє, що DLL передає виклики `ijl15` від гри й ставить хуки. |
| `make_grid_keys.py` | Збирає сітковий `CustomKeys.txt` з файлів вашої гри: позиції кнопок бере з `Units\*Func.txt` в MPQ, підказки — з `CustomKeysSample.txt` гри (тому мова та сама, що в грі). Має крихітний читач MPQ на стандартній бібліотеці. |
| `build.cmd` | Збирає DLL. |

Готова `orc_hints.dll` лежить у [Releases](https://github.com/stratiiv/wc3-orc-overlay/releases).

## Встановлення

Перевірено в тестовій програмі на Windows 11; зроблено для Warcraft III 1.26a. WFE не потрібен.

1. Закрийте гру й запустіть `powershell -ExecutionPolicy Bypass -File setup\install.ps1`. Якщо гра не в `C:\Program Files (x86)\Warcraft 3`, додайте її папку аргументом.
2. Запускайте гру через `war3.exe`. Приблизно за 10 секунд DLL запрацює.

Гра сама завантажує `ijl15.dll` зі своєї папки, тому скрипт перейменовує справжню DLL на `ijl15_orig.dll` і ставить цю на її місце; усі виклики `ijl15` передаються оригіналу. Щоб скасувати, видаліть `ijl15.dll` і поверніть назву `ijl15_orig.dll`. Якщо поруч працює WFE (він ховається в трей), він усе одно завантажить свою DLL, тому закрийте його.

Скрипт також переносить іконки з неправильною буквою в `ReplaceableTextures_wrong_letters`, вимикає власні хоткеї, ставить `maxfps` 75 і копіює стандартну камеру, якщо збереженої ще немає.

За бажанням, сіткові хоткеї: встановіть [Python 3](https://www.python.org/downloads/) і запустіть `python make_grid_keys.py "C:\Program Files (x86)\Warcraft 3"` від адміністратора. Потім у грі увімкніть **Options → Gameplay → Custom Keyboard Shortcuts**.

> Сторонні DLL можуть банити на community-серверах (iCCup тощо). Це для ігор проти ШІ.

## Такий самий сетап на іншому ПК

Самої гри й набору іконок із буквами в репозиторії немає: скопіюйте папку гри на інший ПК, клонуйте репозиторій (або завантажте ZIP) і запустіть скрипт вище. Якщо DLL не зібрана, він завантажить її з релізу.

## Клавіші

| Клавіша | Дія |
|---------|-----|
| `Page Up` / `Page Down` | віддалити / наблизити камеру |
| `Ctrl+Page Up` / `Ctrl+Page Down` | нахилити камеру пологіше / крутіше |
| `Home` | таймер підказок знову з 00:00 |

## Налаштування

- `orc_hints.txt`: рядок `m:ss текст` показується на цей час матчу.
  Рядки з `#` — коментарі. Гра читає файл під час запуску.
- В `orc.c` (після змін зібрати заново): `MSG_MS` (скільки висить рядок),
  `MAX_MSG`, `CHAT_X`, `CHAT_BOTTOM` (де рядки), `ZOOM_*` і `TILT_*` (кроки й межі камери).

Таймер рахує реальний час, поки йде матч. Якщо поставити одиночну гру на паузу через меню, він може
втекти вперед; натисніть `Home` на старті матчу, щоб вирівняти.

## Збирання DLL

```
winget install MartinStorsjo.LLVM-MinGW.MSVCRT
build.cmd
```

## Як це працює

- DLL створює тимчасовий пристрій D3D8/D3D9, щоб знайти адреси `Present` і `Reset` у `d3d8.dll` / `d3d9.dll`.
  На Windows 10/11 у кожного пристрою своя vtable, тому DLL перехоплює сам код функції за схемою гарячого
  латання Microsoft (`mov edi, edi` плюс 5 байтів-заповнювачів).
- У `Present` вона малює рядки чату з одного текстурного атласу і відновлює стан пристрою через state block.
  Перед `Reset` (наприклад, на Alt+Tab) звільняє свої ресурси.
- З `game.dll` 1.26a вона читає два значення (чи йде матч і чи відкрито поле чату) і пише два: дальність
  і кут камери, для зуму й нахилу. Адреси взято з плагіна `Camera.mix` від SLAVA_DROM. На іншій версії гри DLL перевіряє
  розмір модуля й поточну дальність і нічого не робить.
- DLL підміняє віконну процедуру гри, щоб ловити `PageUp` / `PageDown` / `Home`.
